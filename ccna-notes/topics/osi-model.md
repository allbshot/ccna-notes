Quick reference notes. Replace/expand as you study.

## The 7 Layers

| # | Layer | Examples / Notes |
|---|---|---|
| 7 | Application | HTTP, DNS, DHCP |
| 6 | Presentation | Encryption, encoding |
| 5 | Session | Session establishment/teardown |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP, routing |
| 2 | Data Link | MAC addresses, switches |
| 1 | Physical | Cables, signals |

## Mnemonic

"All People Seem To Need Data Processing" (top to bottom, 7→1)
